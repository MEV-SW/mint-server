# 결정기록_2026-09-16_B3-임계값-확정

- 관련: [#30 [이슈레이더/B3] 운영표본 재보정 + 골든 평가셋](https://github.com/MEV-SW/mint-server/issues/30) / 결정자: yschae0311

## 무엇을 바꾸나

B3 완료 판정 기준이 요구한 "운영 표본 300~500건 + 라벨셋(~150쌍)으로 근접중복·사건 임계값 확정, 골든셋 CI 회귀 편입"을 생략한다.
대신 담당자가 운영 배포 경험을 바탕으로 기존 B2 실험값(`near_dup=0.90`, `event=0.84`)을 그대로 최종 합격선으로 채택한다.
[`app/core/config.py`](https://github.com/MEV-SW/mint-server/blob/main/app/core/config.py)의 PROVISIONAL 주석을 확정으로 바꾸고, [기능 문서 인덱스](https://github.com/MEV-SW/mint-server/blob/main/docs/기능/README.md)의 "임계값 임시" 표기를 "임계값 확정"으로 바꾼다.

## 왜

이슈 레이더가 이미 프로덕션에 배포돼 실제로 돌고 있고(`ISSUE_RADAR_ENABLED=true`), 담당자가 그 운영 결과를 보고 현재 수치가 합격선으로 충분하다고 판단했다.

## 버리는 것

- `scripts/experiments/issue_clustering/label_cli.py`·`calibrate_thresholds.py`로 준비된 운영표본(`data/op_corpus.jsonl`, `op_candidates.jsonl`)에 대한 실제 라벨링 작업 — 도구는 남아있고 필요해지면 그때 실행한다.
- `golden_set.jsonl`·`thresholds.json` 커밋과 그에 의존하는 [`tests/test_golden_clustering.py`](https://github.com/MEV-SW/mint-server/blob/main/tests/test_golden_clustering.py) CI 회귀 — 두 파일이 없는 채로 계속 skip 상태로 남는다.
- precision·recall을 수치로 뒷받침하는 근거 — "임의 수치 아님"이라는 원래 기준 대신 운영 경험 기반 판단으로 대체됐다.

## 대안과 기각 이유

- 정식 라벨링 진행 후 확정 — 담당자가 지금 시점에 불필요하다고 판단, 보류.
- 임계값을 더 보수적으로(추정치가 아닌 값으로) 바꾸기 — 별도 근거 없이 바꿀 이유가 없어 기존값 유지가 채택.
