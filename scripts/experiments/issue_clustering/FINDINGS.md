# B2 실험 결론 — 이슈 클러스터링

- 일자: 2026-09-10
- 담당: 채윤성 (yschae0311)
- 상태: **방법 성립. B3 재분할 불필요.** 운영 표본으로 임계값 1회 재보정 조건.

## 한 줄

임베딩(코사인) + 시간창 + union-find 로 "같은 사건" 묶음이 된다.
하드한 조건(관련성 게이트 전, 제목만)에서도 클러스터 precision ≈ 90%.

## 실험 조건

| 항목 | 값 |
|---|---|
| 코퍼스 | RSS 14개 피드 지금 크롤, 280건 (10개 피드 응답, 276건 날짜 있음), 최근 ~2주 |
| 임베딩 | `cohere.embed-multilingual-v3` (Bedrock, us-east-1), 1024차원, L2 정규화 |
| near-dup | 코사인 ≥ 0.90, 시간창 없음 |
| event 클러스터 | 코사인 ≥ 0.84, ±7일, single-linkage(union-find) |

임베딩 공간 확인: 최근접 이웃 코사인 p50=0.70, p90=0.87, p95=0.94, p99=1.00.
→ 0.84는 상위 ~8%만 이웃으로 인정하는 지점. 무관한 기사쌍이 우연히 넘는 일은 드물다.

## 결과

**event 클러스터 @ 0.84 — 13개 다중기사 클러스터 / 32건 / 9개는 2개 이상 매체**

| 판정 | 개수 | 예 |
|---|---|---|
| 정확 | 11 | 기아 화성 PBV 공장 견학(3매체), 르노코리아 보증연장(3건), 제네시스 마그마 르망, 폴스타 콘셉트카, MCEE 신재생 지침 고시(피드 2개 교차) |
| 정확 + "정정" 케이스 | 1 | `R&D 공고` + `R&D 공고(정정)` — 추적하려는 "같은 항목 갱신" 바로 그 경우 |
| 경계(변호 가능) | 1 | 홈쇼핑 재승인 기사 2건(같은 결정, 다른 각도) |
| 오병합 | 1 | ASF 야생멧돼지 주간 검사결과 5건 — 같은 사건이 아니라 **정기 시리즈** |

- 클러스터 precision: 12/13 (엄격 11/13). 유일한 오병합(ASF)은 (a) near-dup 층이 sim 0.99로
  이미 잡고 (b) EV/자율주행 관련성 게이트가 어차피 제거한다.
- event-sim을 0.80으로 낮추면 오병합이 늘었다: 르노 클러스터에 "임단협 조인식"(다른 사건, 같은 회사),
  R&D 공고에 "CCU 실증센터"(다른 사업)가 붙었다. **0.84에서 둘 다 깨끗이 분리됨.**
  → 사용 가능 구간은 코사인 **0.83–0.85**.

**near-dup @ 0.90 — 10개 그룹, 전부 진짜 중복/정정**

- 매체만 다른 동일 사건쌍(현대차 모빌리티학교, BMW X5, 애플 폴더블 등)과
  `공고 ↔ 공고(정정)`, 연합뉴스 `[영상] ↔ [쇼츠]` 를 정확히 잡음. 오탐 0.
- 이 층이 `issue_revision`(중복 보도 추가 vs 실질 변화 구분)의 1차 필터가 된다.

## 데이터 모델 함의 (B1 계약 입력)

두 층 구조가 그대로 스키마로 매핑된다:

```
issue            (사건)      ← event 클러스터 (코사인 ≥ 0.84, ±7d)
issue_revision   (변화 이력)  ← near-dup(≥0.90)=중복/정정,  0.84~0.90=실질 추가
issue_member     (기사 N:1)
user_issue_seen  (마지막 확인 커서) ← "마지막 확인 이후 변화"의 핵심
```

증분 배정(운영): 새 기사 → 시간창 내 기존 issue centroid와 kNN →
≥0.84 이면 합류, ≥0.90 이면 revision으로도 기록, 아니면 새 issue.
벡터 인덱스는 이미 스택에 있는 **Elasticsearch dense_vector** 재사용 (pgvector 추가 불필요).

## 잔여 불확실성 (다음 카드에서 해소)

1. **recall 미측정.** 정답 라벨셋이 없다. → 운영 표본 300~500건에 후보쌍
   라벨링(~150쌍) 만들어 precision/recall 수치화. 이 라벨셋을 리포 자산으로 커밋
   (프로젝트 정의의 "평가셋" 완료 기준).
2. **운영 분포 미검증.** 이 코퍼스는 관련성 게이트 전 + 영어 자율주행 소스 거의 없음
   (Electrek 2건, Autonews 403). 운영 posts 표본으로 1회 재현 필요.
3. **"시리즈 vs 사건" 구분 없음.** ASF 검사결과처럼 near-identical + 정기 주기 + 템플릿
   제목이면 "정기 시리즈"로 표시하고 추적 이슈로 올리지 않는 규칙 필요.
4. **single-linkage 체이닝 위험.** 280건 + 7일창에서는 안 보였으나 코퍼스가 커지면
   centroid 거리 또는 최대 지름 가드 필요.
5. **임베딩 대상.** 제목 + RSS 요약만 썼다. 운영은 `title + AI 요약`으로 임베딩 (본문
   전체는 노이즈). Cohere만 봤고 Titan v2 / 로컬 모델 비교는 안 함 — 필요 시 후속.
6. **피드 날짜 오염.** 일부 항목 연도가 6273 등. 운영은 `published_at` 사용하되 동일한
   sane-range 클램프( `parse_dt` )를 그대로 적용.
7. **리전 분리.** 임베딩은 us-east-1에서만 호출됨. 운영 배포 시 리전/비용/지연 확인.
